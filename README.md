# CapVision Machine Simulator

เว็บจำลองเครื่องตรวจสอบฝาโลหะ: สายพานหลัก → เซนเซอร์ทางเข้า → Encoder → Trigger กล้อง → ผล PASS/FAIL → รีเจค A พร้อมยืนยัน → กระบอก B สำรอง → รางลาดและสายพานรับแยก

## เปิดใช้งาน

Windows: เปิดไฟล์ `เปิด_CapVision_Simulator.cmd` หรือใช้ Python 3:

```sh
python bridge/server.py --open
```

เข้าเว็บที่ `http://127.0.0.1:8768` แล้วกด **เริ่มสาธิตครบวงจร** โหมดเว็บใช้ผลตรวจจากกล้องจำลอง

ตัวเว็บใช้ Three.js ที่รวมอยู่ใน `dist/vendor` และ C/WASM ที่รวมอยู่ใน `dist/assets` ไม่ต้องติดตั้งแพ็กเกจ JavaScript เพื่อเปิดใช้งาน

## W3 — ปรับการหมุนมุมมอง

- มุมภาพรวมใช้โมเดล 116,217 สามเหลี่ยม ขนาด 6.5 MB แทน 393,352 สามเหลี่ยม ขนาด 22.5 MB
- รายละเอียดตู้ PLC โหลดแยกเมื่อเปิดดูตู้หรือซูมเข้าใกล้ แล้วกลับใช้โมเดลเบาเมื่อถอยออก
- แคชเงาโครงเครื่อง แทนการวาดเงาใหม่ทุกเฟรม
- วาดฝาหลายใบด้วย instancing และใช้วัสดุร่วมกัน
- มีคุณภาพภาพ **อัตโนมัติ / เน้นลื่น / เน้นคมชัด** การปรับภาพไม่เปลี่ยนรอบจำลอง PLC 10 ms
- จุดหมุนลูกกลิ้งรักษาแนวเพลาจริง โดยไม่แกว่งออกจากตลับลูกปืน

## ทดสอบ

ใช้ Node.js และ Python 3 ที่ติดตั้งในเครื่อง:

```sh
node tests_engine.mjs
node tests_kinematics.mjs
node tests_shaft.mjs
node tests_render_budget.mjs
node tests_mailbox.mjs
python tests_bridge.py
```

## โครงสร้าง

- `dist/`: เว็บและโมเดลพร้อมใช้งาน
- `bridge/`: Local bridge, SLMP และส่วนต่อ MX Component
- `PLC/`: โปรเจกต์และชุดคำสั่งนำเข้า PLC
- `tools/`: ส่งออกโมเดลจาก Blender; ต้องมีต้นฉบับ Blender ใน workspace เดิมเมื่อต้องการสร้างโมเดลใหม่
- `README_TH.md` และ `dist/manual.html`: คู่มือภาษาไทย

ส่วน Bridge เริ่มแบบไม่เชื่อม PLC และไม่เปิดสิทธิ์ควบคุมโดยอัตโนมัติ ยังไม่ได้ทดสอบกับ PLC จริงหรือ MX Component ในเครื่องนี้ ภาพ Safety เป็นการจำลอง; ระบบ Safety เครื่องจริงต้องเป็นวงจรฮาร์ดแวร์ตามแบบ

การเคลื่อนฝาเป็นการจำลองทางเรขาคณิตสำหรับนำเสนอ ไม่ใช่การคำนวณการชนแบบ rigid-body และไม่ได้ประมวลผลภาพกล้องจริง
