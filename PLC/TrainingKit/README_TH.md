encoder เป็นตัวสำหรับศึกษาเท่านั้น **ไม่ได้ต่อกับเพลามอเตอร์** ให้หมุนด้วยมือหรือติดลูกบิดไว้ ส่วนมอเตอร์ทำงานแยกอิสระ

## 1. ตาราง I/O (ใช้ค่าตั้งต้นนี้ ถ้าชุดฝึกต่อไว้ต่างจากนี้ ให้แก้ใน .txt แล้วรัน build ใหม่)

| ขั้ว | อุปกรณ์ | ชนิดหน้าสัมผัส | หมายเหตุ |
|---|---|---|---|
| X7 | ปุ่ม START สีเขียว | NO | สั่งงานที่ขอบขาขึ้น ถ้ากดค้างไว้ตอนเปิดเครื่อง มอเตอร์จะไม่หมุน |
| X10 | ปุ่ม STOP สีแดง | **NC** | ถ้าสายขาด มอเตอร์จะหยุด (fail-safe) |
| X11 | ปุ่ม RESET สีเหลือง | NO | ใช้รีเซท Fault และล้างค่านับของ encoder |
| X15 | หน้าสัมผัส Overload 95-96 | **NC** | ถ้าไม่มี OL ให้จั๊มป์ X15 ลง 0V |
| X4 / X5 | Encoder เฟส A / B | NPN | ใช้ HSC CH3 แบบ 2 เฟส |
| Y3 | รีเลย์ K1 → มอเตอร์ | รีเลย์ 24VDC | ห้ามขับมอเตอร์ตรงจากขั้ว Y |
| Y10 / Y11 / Y12 | ไฟ RUN / พร้อม / FAULT | – | ไฟ FAULT กระพริบทุก 1 วินาที |
| Y13 | ไฟ ENC | – | ติดครึ่งรอบ ดับครึ่งรอบ หมุน encoder ช้า ๆ จะเห็นชัด |

เลือก I/O ชุดเดียวกับ CapVision (START X7, STOP X10, RESET X11, มอเตอร์ Y3) เพื่อให้จำได้ง่าย ส่วน X4/X5/X15 เป็นขาที่ CapVision ไม่ได้ใช้

## 2. Device ที่ใช้ดูขณะ Monitor

| Device | ความหมาย |
|---|---|
| M10 | มอเตอร์ได้รับคำสั่ง RUN (seal-in) |
| M12 | Fault Overload ค้างอยู่ |
| D100 (32 บิต) | ค่านับปัจจุบันของ encoder (อ่านจาก SD4560) |
| D130 (32 บิต) | PPR หรือจำนวนพัลส์ต่อรอบ ค่าเริ่มต้น **600** (แก้ได้ขณะ Online) |
| D140 / D142 | จำนวนรอบสะสม / เศษพัลส์ในรอบปัจจุบัน |
| D170 (32 บิต) | ความเร็ว รอบ/นาที (คำนวณทุก 1 วินาที ค่าเป็นลบเมื่อหมุนกลับ) |
| M20 | ON เมื่อหมุนไปข้างหน้า |

## 3. Encoder ที่แนะนำ

ใช้รุ่นที่ไฟเลี้ยง **5–24V** และเอาต์พุตแบบ **NPN open collector** เช่น LPD3806-600BM-G5-24C (600 P/R)
ราคาถูก มีเพลาให้ติดลูกบิดหมุนมือได้ และสีสายตรงกับแบบ: น้ำตาล = +V, ฟ้า = 0V, ดำ = A, ขาว = B
- **อย่าใช้รุ่น Line driver (5V RS-422)** เพราะต่อเข้า X ของ FX5U ตรง ๆ ไม่ได้
- ถ้าใช้รุ่น PNP ต้องเปลี่ยนการต่อ S/S ไปที่ 0V (Source) และเปลี่ยนปุ่มทุกตัวให้ต่อไปที่ +24V แทน

## 4. ตั้งค่าใน GX Works3 (ทำครั้งเดียว)

1. สร้างโปรเจกต์ใหม่ ซีรีส์ FX5CPU รุ่น FX5U ภาษา Ladder
2. ไปที่ Navigation → Parameter → FX5UCPU → Module Parameter → **High Speed I/O** → Input Function → **High Speed Counter** → Detailed Setting
   - **CH3**: Use/Not use = Use, Operation Mode = Normal, Pulse Input Mode = **2-Phase 1 Multiple**
   - ตรวจว่าขั้วที่ระบบกำหนดให้ CH3 คือ **A = X4, B = X5** (ดูช่อง Input Assignment ในหน้าจอเดียวกัน)
   - ถ้าเลือก 2-Phase 4 Multiple จะได้ 2400 พัลส์ต่อรอบ ให้แก้ `DMOV K600 D130` เป็น `K2400`
3. นำเข้า Ladder: เปิดโปรแกรม MAIN → Project → Open Other Data → Open CSV File (หรือคำสั่ง Read from CSV File ใน GX Works3 บางเวอร์ชัน) เลือก `TK_Motor_Encoder_IMPORT.csv`
4. Convert (F4) → Online → Write to PLC (ติ๊ก Parameter + Program) → สั่ง Reset หรือปิด-เปิด PLC เพื่อให้ Parameter มีผล → RUN

> ⚠️ **ยังไม่ได้ทดสอบกับ GX Works3 และ FX5U จริง** ต้องตรวจ 3 จุดต่อไปนี้ใน GX Works3 ก่อนใช้งาน
> ทั้ง 3 จุดเขียนตามคู่มือ FX5 แต่ถ้า GX Works3 แจ้ง error ตอน Convert หรือเลขในหน้า Parameter ไม่ตรงกับที่ระบุไว้ ให้ยึดตามเครื่องจริง
>
> | จุดที่ต้องตรวจ | ที่ใช้ในโปรแกรมนี้ |
> |---|---|
> | Device ค่านับปัจจุบันของ CH3 | `SD4560` |
> | ค่าบิตที่ใช้สั่งเริ่มนับ CH3 | `HIOEN K0 K4 K0` (บิต 2) |
> | รูปแบบคำสั่งเปรียบเทียบ 32 บิต | `LDD>` |

## 5. ขั้นตอนทดสอบบนชุดฝึก (ทำตามลำดับ)

| # | ทำ | ต้องเห็น |
|---|---|---|
| 1 | ยังไม่ต่อมอเตอร์ จ่ายไฟ แล้วสั่ง RUN | ไฟ Y11 ติด, Y3 ดับ, ไฟ LED ขา X10 และ X15 **ติด** (เพราะเป็น NC) |
| 2 | กด START | Y3 และ Y10 ติด ปล่อยปุ่มแล้วยังติดอยู่ |
| 3 | กด STOP | Y3 ดับ |
| 4 | กด START แล้วถอดสาย X15 (จำลอง OL ตัด) | Y3 ดับ, Y12 กระพริบ, กด START แล้วไม่ติด |
| 5 | ต่อสาย X15 คืน → กด RESET → กด START | Y12 ดับ, มอเตอร์ไม่หมุนเองหลัง RESET, หมุนเมื่อกด START |
| 6 | Monitor D100 แล้วหมุน encoder ตามเข็ม 1 รอบ | D100 เพิ่มขึ้นประมาณ 600 (ถ้าลดลง ให้สลับสาย A/B) |
| 7 | หมุน encoder ต่อเนื่องประมาณ 1 รอบต่อวินาที | D170 ≈ 60, M20 ติด, Y13 กระพริบ |
| 8 | กด RESET | D100 = 0 |
| 9 | ต่อมอเตอร์จริงผ่าน K1 แล้วทำข้อ 2–3 ซ้ำ | มอเตอร์หมุนและหยุดตามปุ่ม |

## 6. ความปลอดภัย
- ปุ่ม STOP ในชุดนี้**ไม่ใช่ E-STOP** ถ้ามอเตอร์เป็นไฟ 220V ต้องมี E-STOP ที่ตัดไฟวงจรกำลังโดยตรง ไม่ผ่าน PLC
- ใส่ไดโอด 1N4007 คร่อมคอยล์รีเลย์ K1 โดยหันขาแถบไปทาง +24V (ฝั่ง Y3)
- ถ้า PLC เป็นรุ่นเอาต์พุตทรานซิสเตอร์ (MT/ES) ต้องต่อ COM ไป 0V และต่อโหลดระหว่าง +24V กับขั้ว Y
